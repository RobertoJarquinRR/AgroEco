# Agro-Eco

Sistema de monitoreo y administración de cultivos en zonas rurales mediante sensores Arduino y un sistema automatizado para la recopilación, organización y presentación de información.

## Descripción

Agro-Eco es un proyecto desarrollado para facilitar el monitoreo y la administración de cultivos en zonas rurales mediante el uso de sensores de hardware conectados a dispositivos Arduino.

El sistema recopila diferentes tipos de datos relacionados con las condiciones de los cultivos y los organiza para facilitar su análisis. A partir de estos datos, Agro-Eco permite generar informes automatizados utilizando modelos predefinidos, facilitando la lectura y comprensión de la información obtenida.

El proyecto busca ayudar a prevenir problemas relacionados con plagas, descuidos y negligencia en el manejo de los cultivos, proporcionando un mayor control sobre las condiciones en las que se encuentran las plantas y permitiendo tomar decisiones basadas en los datos recopilados.

## Características

- Registro y administración de cultivos.
- Registro de usuarios o agricultores.
- Recepción de datos provenientes de sensores Arduino.
- Monitoreo de temperatura.
- Monitoreo de humedad.
- Detección de valores fuera de los parámetros establecidos.
- Generación automática de informes.
- Almacenamiento de datos históricos.
- Consulta de informes anteriores.
- Visualización de datos mediante gráficos.
- Generación de alertas.
- Administración de diferentes cultivos o parcelas.

## Sensores utilizados

### DHT22

Sensor utilizado para obtener:

- Temperatura ambiental.
- Humedad ambiental.

### DS18B20

Sensor utilizado para medir la temperatura.

## Tecnologías utilizadas

### Lenguajes y tecnologías

- **HTML** — estructura de las interfaces.
- **CSS** — diseño y estilos de las interfaces.
- **JavaScript** — interacción y comportamiento de las interfaces.
- **C#** — lógica principal y procesamiento de la información.
- **C++** — programación de los dispositivos Arduino y manejo de los datos provenientes de los sensores.
- **WPF** — desarrollo de la interfaz de la aplicación de escritorio.

### Librerías y dependencias

- `System.IO.Ports` — comunicación mediante puertos seriales.
- `System.Reactive` — manejo de eventos y flujos de datos.

### Herramientas

- **Visual Studio 2022** — desarrollo principal del proyecto.
- **Visual Studio Code** — desarrollo y edición de código.
- **GitHub** — almacenamiento, control y seguimiento del código fuente.
- **Trello** — organización y administración de las tareas del proyecto.

## Metodología

Para la administración y organización del desarrollo de Agro-Eco se utilizó la metodología **Scrum**, apoyándose en Trello para gestionar las tareas, organizar los avances y llevar un control de los plazos de entrega.

## Requisitos

Para utilizar Agro-Eco se necesita:

- Una computadora.
- Los componentes de hardware necesarios para el sistema.
- Dispositivo Arduino.
- Sensores DHT22 y DS18B20.
